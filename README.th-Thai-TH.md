## คุณสมบัติ

### องค์กรและกราฟความสัมพันธ์

- **ผืนกราฟแบบต้นไม้ขององค์กร**: องค์กรถูกจัดวางเป็นต้นไม้ ลากเพื่อปรับระดับชั้นและลำดับพี่น้อง
- **ตัวตนและการดำรงตัวตน**: บุคคลหนึ่งสามารถดำรงตัวตนได้หลายตัวตนในหลายองค์กร จัดเรียงตัวตนใหม่หรือย้ายทั้งกลุ่มไปยังองค์กรอื่นได้ พร้อมเส้นบุคคลและเส้นความสัมพันธ์ที่ตามไปด้วย
- **เส้นความสัมพันธ์**: ลากเส้นความสัมพันธ์สองทิศจากชิปสีของบุคคล (เช่น "สั่ง ⇌ เชื่อฟัง")

### การรองรับหลายภาษา

- **ภาษาของหน้าจอ**: สลับหน้าจอได้สิบภาษา
- **ภาษาอ้างอิงหลัก**: ภาษาอ้างอิงหลักสำหรับชื่อของแต่ละฐานข้อมูล ชื่อที่ไม่ได้แปลจะแสดงค่าภาษาอ้างอิงหลักแทน
- **ภาษาที่เปิดใช้**: กำหนดได้ว่าจะป้อนชื่อด้วยภาษาใดบ้าง

### การทำงานร่วมกัน

- **การร่วมแก้ไขแบบเรียลไทม์หลายผู้ใช้**: หลายคนแก้ไขพร้อมกันได้ การเปลี่ยนแปลงซิงก์ไปยังทุกไคลเอนต์ทันที
- **เมทาดาทา**: ฐานข้อมูลแต่ละฐานตั้งค่าชื่อที่แสดงและสีพื้นหลังได้

### การส่งออก

- **PNG / SVG**: ส่งออกภาพ แต่ละแบบมีรูปแบบทั้งหมดและปัจจุบัน
- **JSON**: ข้อมูลทั้งหมด รวมถึงเมทาดาทาและชื่อในทุกภาษาที่เปิดใช้
- **DB**: สำเนาฉบับสมบูรณ์ของไฟล์ฐานข้อมูลดิบ ใช้เป็นการสำรองข้อมูลได้ทันที

## เริ่มใช้งานอย่างรวดเร็ว

```bash
node server.js          # optional --port / --host
```

- พาธราก `/`: หน้าแรกสำหรับสร้างฐานข้อมูลใหม่
- `http://localhost:PORT/<database-name>/` (เช่น `/smr/`): เข้าสู่ฐานข้อมูล ฐานข้อมูลที่มีอยู่เปิดได้โดยตรงที่พาธของตน
